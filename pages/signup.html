Get Started with GameLog

Keep track of your video game collection in one place.

GameLog allows you to add games, update their playing status, search your library, and upload game cover images.

Development Accounts

GameLog is currently a development project. Instead of creating a new account, you can sign in using one of the provided test accounts.

How to Sign In

  1. Click the Log In button below.
  2. Open your browser's developer console using F12 or by right clicking and selecting inspect.
  3. Find the ADMIN and USER test credentials.
  4. Enter a username and password to sign in.
Log In to GameLog

Note: GameLog uses browser sessionStorage. Game information is temporary and may be cleared when the browser session ends.
